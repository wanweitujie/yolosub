# src/ 下预置离线权重说明(勿删)

> **警告**:本目录下的 `yolo26n.pt` 与 `yolov5n.pt` 是**有意预置的离线权重**,用于 AMP(混合精度)自检。禁止删除、移动或改名,否则训练启动会退回联网下载,慢且可能卡死。

## 为什么存在

ultralytics(YOLOv8/v11)与 YOLOv5 在训练启动时都会做 AMP 兼容性自检,加载固定简写名的权重:

- **v8/v11(8.4.x)**:`check_amp` 固定加载 `YOLO("yolo26n.pt")`,相对训练子进程 CWD 解析。本项目训练子进程 CWD = `src/`(见 `src/train_v/manager.py`)。
- **v5**:`check_amp` 的兜底分支 `DetectMultiBackend('yolov5n.pt')`,同样相对 CWD 解析(见 v5 `utils/general.py` check_amp)。

若文件缺失,框架会尝试联网下载:
- `yolo26n.pt` 来自 `github.com/ultralytics/assets`,实测 github 限速,一次下载曾耗时 5 分 34 秒;
- `yolov5n.pt` 来自 `github.com/ultralytics/yolov5` release(v6.1),且 v5 的 `attempt_download` **无超时控制**,受限网络下可能直接卡住训练。

## 注意事项

1. **两个文件已纳入 git 版本管理**(随代码一起 clone/同步,不依赖本地手工放置)。`git clean -fdx` 不会删除已跟踪文件,但请勿用其清理本目录其他未跟踪产物。
2. **不要随意移动/改名**:框架按相对 CWD 的简写名加载,移动后需同步调整训练子进程 CWD 或预置路径,否则回到联网下载。
3. 配套的离线防护环境变量(`YOLO_OFFLINE` / `YOLOv5_OFFLINE`、`YOLO_AUTOINSTALL` / `YOLOv5_AUTOINSTALL`)已在 `src/utils_v/index.py` 的 `set_yolo_env()` 中设置。
4. 若确需从零重建:从下方来源下载同名文件放入本目录即可,字节数应与上表一致(不一致说明版本不符,勿用)。
